# R0 implementation contract

Status: approved implementation contract; based on the independently reviewed 2026-09-24 audit. The archived findings and their reachability limits remain authoritative. Add no adjacent product scope. Each lane first adds a regression test that fails on baseline behavior, then implements only its row below. Keep existing exported APIs and wire/config shapes unless a row explicitly requires correcting an existing input contract. If a fix needs another lane's files, coordinate before editing.

## Cross-lane acceptance boundary

- Regression tests must compile and fail against the `0014900` implementation because the observed behavior violates the intended contract; missing symbols, compile errors, or zero matched tests are not valid red evidence. After the fix, rerun the same tests and the affected package race suite. Archived reproducer `PASS` means only that the old bug was observed.
- Keep the report's trigger limits: `--no-auth` plus wildcard is the serve exposure; MCP cross-origin is conditional on the configured endpoint returning a foreign absolute SSE endpoint or cross-origin redirect; MCP replay is the lost-response ambiguity; provider resolution covers the actual CLI factory; trace privacy covers the default prompt/REPL emission path. Plan Mode's R0 name allowlist only closes unknown-tool behavior; same-name custom-tool identity spoofing and the long-term D-01 permission policy remain deferred to R4.
- R0 does not implement the R3 provider protocol, R4 general tool-effect system, R5 full TUI journey, R6 ACP interoperability/MCP lifecycle, or R7 tracing architecture. R9's three tasks for automatic cross-process action resume remain deferred.
- Each builder makes an isolated commit. The main branch records a lane as done only after the commit has been cherry-picked and independently reviewed. Each builder records test names, exact commands, exit codes, and commit in the execution ledger. Static review, a targeted unit test, affected-package race, and full `make verify` are distinct evidence; do not claim an unrun check.
